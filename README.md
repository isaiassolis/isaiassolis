## 👋 Acerca de este portafolio

Soy **Isaías Solís**, ingeniero en Sistemas Computacionales con experiencia en dirección de proyectos tecnológicos, desarrollo de productos empresariales e ingeniería aplicada. Actualmente curso una **Maestría en Inteligencia Artificial en UNIR**.

Aquí reúno **proyectos con código, prototipos, investigación y casos de estudio de software empresarial**. Cada repositorio explica qué se desarrolló, mi participación y qué evidencia está disponible. Cuando un producto es privado o pertenece a una empresa, publico únicamente documentación autorizada o material de portafolio.
